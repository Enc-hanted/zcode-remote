# ZCodeRemote

ZCodeRemote 将 [ZCode](https://zcode.z.ai) 桌面端的移动端远控页面封装为 Android 应用，提供悬浮输入框、对话问题导航、新回复通知等增强体验。

> 本应用非智谱官方产品，与 Z.ai / ZCode 官方无关，仅供个人使用与学习。ZCode 及 ZCode logo 为智谱旗下品牌，logo 素材取自 zcode.z.ai 官网。

## 功能

### 入口

- **扫码进入**：扫描桌面端 ZCode 左下角「手机图标」弹出的远控二维码
- **粘贴链接**：支持手动粘贴 `https://zcode.z.ai/remote/...` 链接；启动时剪贴板中若正好是远控链接，会自动预填
- **最近会话**：记录最近 10 条远控链接，点击进入，长按删除
- **自动恢复**：冷启动自动进入上次会话，按返回键返回入口页切换会话

### 使用体验

- **悬浮输入框**：底部输入框默认收起、不占位，可通过悬浮按钮一键展开为全屏输入；右上角圆弧按钮用于收起
- **对话问题导航**：下拉唤出问题列表，拖动悬停可预览，点击条目直接跳转
- **回复通知**：切出应用后收到新回复时，通过系统通知提醒
- **后台不断连**：切出应用后保持连接，回复照常到达
- **征询弹窗**：页面中的询问 / 确认 / 方案征询弹窗会以底部卡片形式显示，选择后自动关闭
- **深色主题**：界面整体采用黑灰配色，与系统深色模式一致

### 安全

- 远控链接本身即是凭证（bearer-link）：本应用不内置任何链接、不上传任何数据，链接仅保存在你的手机中
- 请勿将本应用及其中保存的链接分享给他人——获得链接即获得你桌面端 ZCode 的操作权限
- 非远控链接会先弹窗确认；非 z.ai 域名链接一律在系统浏览器打开；SSL 证书错误一律拒绝访问

## 手势

| 手势 | 功能 |
|---|---|
| 单击 logo | 唤起 / 收起悬浮输入框 |
| 双击 logo | 打开设置 |
| 长按拖动 logo | 调整位置（自动记忆） |
| 下拉 logo | 唤出 / 收起问题导航 |
| 上滑 logo | 跳到底部 |
| 左缘上滑 ×3 + 右缘下滑 ×3 | 显示诊断卡（复制诊断信息） |

## 技术

Kotlin + WebView，minSdk 26（Android 8.0+），targetSdk 35，versionName `0.0.2`。
扫码功能基于 [zxing-android-embedded](https://github.com/journeyapps/zxing-android-embedded)。
